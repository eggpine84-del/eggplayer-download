# 🎬 EggPlayer (에그플레이어)

> **불필요한 기능과 광고를 싹 뺀, 가볍고 빠른 초경량 Win32 네이티브 비디오 플레이어**

EggPlayer는 설치(인스톨러) 과정 없이, 다운로드 후 즉시 실행할 수 있는 고성능 64비트 Windows 전용 미디어 플레이어입니다.

---

## 📥 다운로드 (Download)

오른쪽의 **[Releases]** 메뉴 또는 아래 링크에서 가장 최신 버전을 다운로드하실 수 있습니다:

👉 **[최신 버전 다운로드 (Releases)](https://github.com/eggpine84-del/eggplayer-download/releases/latest)**

1. 최신 릴리즈에서 `eggplayer-v0.1.0-win64.zip` 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 풉니다.
3. `eggplayer.exe`를 더블클릭하면 즉시 실행됩니다!
   *(동영상 파일을 창 위로 드래그 앤 드롭하여 바로 감상하세요.)*

## ✨ 핵심 기능 (Features)

- **정밀 프레임 탐색 (Exact Seek)**
  - 일시정지(멈춘 상태)에서도 좌/우 방향키 입력 시 키프레임 지연 없이 **1초 단위로 화면 프레임이 즉각 찰칵찰칵 갱신**됩니다.
- **통합 환경설정 (F5)**
  - 좌/우 방향키의 탐색 초수(기본 3초)를 사용자의 취향에 맞게 **1초~3600초 사이로 자유롭게 커스텀**할 수 있습니다.
- **연속재생 스마트 큐**
  - 드라마, 애니메이션 등 동일 폴더 내의 연작 파일들을 자동 감지하여 `PageUp` / `PageDown`으로 손쉽게 다음 에피소드를 연속 감상할 수 있습니다.
- **SMI 자막 한글 깨짐 방지**
  - 고전 인코딩(CP949/EUC-KR)과 현대 UTF-8을 자동 판별하여 한글 자막이 외계어로 깨지는 현상을 원천 방지합니다.
- **가벼운 메모리 & No 광고**
  - 무거운 웹뷰(Electron)가 아닌 순수 Win32 네이티브 기반으로 렉 없이 번개처럼 작동합니다.

## ⌨️ 주요 단축키 일람

| 기능 | 단축키 |
| :--- | :--- |
| **재생 / 일시정지** | `Space` 또는 `마우스 좌클릭` |
| **전체 화면 전환** | `Enter` 또는 `마우스 더블클릭` |
| **앞/뒤 탐색** | `방향키 [<-]` / `[->]` (설정된 초 단위 이동) |
| **볼륨 조절** | `방향키 [위]` / `[아래]` 또는 `마우스 휠` |
| **음소거 / 항상 위** | `M` (음소거) / `T` (항상 위) |
| **이전 / 다음 에피소드** | `PageUp` / `PageDown` |
| **재생 배속 조절** | `Z` (1.0배속 리셋) / `X` (-0.1배속) / `C` (+0.1배속) |
| **자막 크기 조절** | `+` (확대) / `-` (축소) |
| **자막 싱크 조절** | `[` (-0.5초 지연) / `]` (+0.5초 앞당김) |
| **환경설정** | `F5` 또는 `마우스 우클릭 -> 환경설정` |
